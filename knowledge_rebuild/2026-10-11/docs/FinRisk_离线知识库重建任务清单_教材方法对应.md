## 每批“效果好”的判据

以下沿用原详细规划的**建议工程门槛**，不是教材承诺，也不是当前已实现的指标。30、100、500各阶段报告实际分母、抽样方式、分层、未知／不适用及首轮／修复后结果；正式全量验收按独立冻结名单进行。

| 检查／指标 | 定义与门槛 | 不允许的替代口径 |
| --- | --- | --- |
| 来源覆盖 | 成功、部分、失败、排除、重复及未处理的集合闭合 | 只统计成功文件 |
| 机械硬检查 | 所有导出中声明有效的证据、版本、引用、ID、枚举、链接和批准范围100%有效 | 机械通过当语义正确 |
| 事实精确率 | 原文支持且归属正确的有值事实／抽审有值事实，≥98% | 只查文字存在，不查主体 |
| 行为完整率 | 正确入库的应有行为／人工从全文列出的应有行为，≥95% | 仅计算生成卡片数 |
| 标签支持精确率 | 条件与归属足够的标签／已赋标签，≥95% | 大量弃标后只报精确率 |
| 应赋标签覆盖 | 正确标签／人工确认应赋标签，≥95%；事实不足另列 | 把0标签当合规 |
| 场景／用途／迁移条件 | 正确判定／可判断项，≥95% | 关键词线索当真实场景 |
| 条件／否定／未知保留 | 正确保留项／必须保留项，≥98% | 未提到改成否 |
| 摘要／规则／前缀支持 | 有证据的实质断言／抽审实质断言，≥98% | 只看表达顺畅或模型总分 |
| 关键错误 | 抽审中伪造原话、错受罚主体、错处罚归属、实质金额错、虚假批准为0；发现后追查影响集合 | 小样0错宣称全库0错 |
| 离线可检索性 | 用独立查询报告命中、排序与失败口径，并定位原因 | 当成比赛分数提升证明 |
| 恢复 | 冻结包可回源，确定性投影／统计可重建，前后指纹一致 | 仅压缩打包就称可复现 |

行为、字段、标签、条件和检索的分母各不相同，必须分别报告。人工复核是知识质量与批准的来源，不是让模型代填human_approved。

## 先做哪些、怎样判定一段工作完成

建议下一段工作集中做S01–S15的**正式化缺口**：重用已有台账与10份样板，补数据契约、机构层级、永久ID和回归，再完成S16的独立30份名单。已经完成的10份候选不从头重做；新实现需要回放时以它们作开发回归材料。

| 里程碑 | 交付 | 达成条件 | 当前状态 |
