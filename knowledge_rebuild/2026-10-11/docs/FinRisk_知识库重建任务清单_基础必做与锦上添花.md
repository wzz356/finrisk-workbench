# FinRisk知识库重建：基础必做与锦上添花

更新：2026-10-10。适用于一周内优先完成离线基础重建的安排。本文件是新版执行优先级；[原40步清单](FinRisk_离线知识库重建任务清单_教材方法对应.md)保留每步细节、教材45项方法和12项实验的完整说明。

取舍原则：来源、主体、事实、处罚归属、条件、证据、审核状态与恢复能力属于基础；研究对照、复杂生成和高级知识发现后置。同一步包含两种动作时拆开处理，不按整步一刀切。

本次只调整清单，未启动全量模型运行，未改桌面项目或冻结包。实际模型渠道、费用上限和持续吞吐尚未确认或实测；历史批处理暂停保持原状。

## 完成口径与当前起点

- 全量台账覆盖9,999份TXT；TXT与PDF属于来源载体，不把19,999个载体计为19,999份独立文书。重复、非目标材料和源信息不足要保留有依据的去向。
- 已有成果直接复用：来源与文本冻结、基础契约和检查工具、27类官方标签、60份发现产生的70个候选因子、10份样板，以及30份模型预审。
- 30份预审已形成49案、97条行为/责任候选、1028条定位证据；修正16项问题，13份模型认为可供验收，17份仍需人工核定。304个交付文件完整性通过，真实人工批准为0。
- “全量处理覆盖”要求每份有去向；“全量候选重建完成”还要求目标材料成功生成有效候选，或有明确的重复、非目标、信息不足等结论。失败隔离不能冒充重建成功，未解决失败必须单列数量和影响。
- “正式批准库”只包含实际人工批准的字段与用途范围；其余保留candidate、pending或隔离状态。完成全量候选不等于每条知识都获人审批准。

## 第一部分：基础必做

### B01 复用来源台账与冻结原文

**对应：**S01–S05、S40基础部分。**状态：**来源冻结已完成，疑点核查与展示脱敏仍有剩余。

- [ ] 复用现有9,999份TXT和源指纹；核对新运行的目标集合、版本与6个保护对象，不重新搬一遍相同原件。
- [ ] 保留原字节、文本版本、逐字证据坐标以及PDF回链；金额断行、表格错列和疑似错配才定向查看PDF，未核范围明确标注。
- [ ] 保留权限与资料来源标记；公开展示的联系方式、账号等按需脱敏。来源文字不能改变审批或执行动作。

**交付／通过条件：**每份目标材料可回源，处理集合闭合，旧库、真实审批和历史暂停不变。教材：证据分层与回源，第92–93页；脱敏与权限，第80、93–94页；原媒体保存，第100页。

### B02 固定最低必要数据契约

**对应：**S06–S10。**状态：**规范和工具已有，30份实例已验证，全量质量未验收。

- [ ] 固定八表、永久ID、文本版本和审核状态；核心包括受罚主体、行为/责任、处罚、日期、条件、标签、场景和逐字段证据。
- [ ] 一案一个受罚主体；直接实施与管理责任分开；机构层级仅按明示事实登记，同名与同文书不自动合并。
- [ ] 沿用27类标签与70个候选因子，只抽取适用模块。缺失字段由程序补null及原因，不要求模型逐条复述全部空字段；0标签不等于合规。
- [ ] 保留否定、申辩、撤销、未知和历史适用范围，未核的法条现行效力不补结论。模型意见与真实批准分开。

**交付／通过条件：**契约版本固定、候选状态可区分、非空事实均有证据；候选因子不冒称已获专家认可。教材：结构化与丰富卡片，第75–78页；qualification，第93页；核心＋领域扩展，第98–99页。

### B03 接通可连续运行的批处理

**对应：**S11–S15、S17、S20、S30基础部分。**状态：**单批工具可复用，新的全量连续流程待接通；这是首要工作。

- [ ] 将全文抽取、程序检查、模型复核、修订和导出分成独立任务队列；单份完成即保存，不等待整组收尾。
- [ ] 复用10份样板和30份预审作为开发回归。保留逐字匹配、重复引文、归属、金额、ID和双向引用检查，覆盖全部输出。
- [ ] 用首批实际运行记录每份耗时、成功/失败、截断、token用量、可得费用和重试；依据实测确定并发，不能先宣称日产量。
- [ ] 缓存绑定来源SHA、契约、字典、提示词和可得模型配置；重复运行不新增相同记录，只重试失败或失效任务。保留两轮修订上限，超限转问题队列。
- [ ] 新运行使用独立目录和状态账本；不得借新清单自动恢复历史质量暂停、沿用过期预算或伪造人审。

**交付／通过条件：**断点续跑、单份隔离、实际产能及成本可核查，旧版本不覆盖。教材：类型状态，第76–77页；提案/审核与主动取证，第92–96页；缓冲批处理与缓存，第78–79、97页。

### B04 审计旧稿并推进全量候选

**对应：**S02、S13、S18–S20。**状态：**新方案全量迁移和扩批尚未开始。

- [ ] 核对旧100＋698份草稿的实际集合；逐份检查来源、字段、证据和状态，分流为可复用候选、修复、重抽、隔离/排除待审。旧稿不能当金标。
- [ ] 既有字段批准仅在同源、同值、同字段范围下继承；新增字段、概括和派生内容另审，拆合保留ID映射。
- [ ] 首100份完成产能和质量检查后推进500份，再处理剩余来源；按批检查关键错误，问题规则修复后回放受影响记录。
- [ ] 对有意义的正文记录事实、行为、程序文字、排除或未解决去向。源不足保留已有事实和缺口，不用模型推测补齐。

**交付／通过条件：**各批实际集合与全量去向闭合，失败不算成功；旧审批及暂停保留。教材：写入比较与历史，第78页；来源整理，第93页；受控更新，第100–101页。

### B05 对复杂材料强制复核，对简单材料随机复核

**对应：**S14、S16–S18、S31–S32。**状态：**30份模型预审完成；新的抽样规则和人工验收待落实。

- [ ] 全部材料做完整抽取与程序硬检查。强制模型复核多主体处罚归属、多决定、分项/总金额、否定撤销、个人责任与机构行为关联、源冲突，以及程序无法解决的证据语义疑点。
- [ ] 简单、结构稳定材料按每批随机10%、至少10份复核；批次不足10份全部复核。此比例是本轮工程起始值，不是教材保证；质量不稳时提高比例或暂停受影响类型。
- [ ] 不能把7,941份机械关注信号全部当成已确认疑难材料。复核触发器需按实际结构与歧义校准，弱案由可以保留未知，不要求为其创造细节。
- [ ] Reviewer阅读全文，输出问题字段、理由、证据和修改要求，不重复生成整套候选。复杂事项允许回查原件，无法解决的交人工。
- [ ] 人工验收优先处理已知关键争议，同时保留独立随机/分层抽样。新确认样本与开发材料隔离；原30份模型先审，不当作提案前独立人审基准。

**交付／通过条件：**有抽样名单、随机种子、触发理由、首轮与修复后结果；模型意见不转成人工批准。同模型共享偏差、实际人审规模和未解决项如实报告。教材：分层评估，第73–74页；独立审核，第92页；候选核验，第100–101页。选择性复核是为本项目期限做的工程取舍。

### B06 生成最低必要的离线使用产物

**对应：**S21、S23–S25、S27–S30基础部分、S33基础部分。**状态：**样板和30份验收入口已有，全量派生待做。

- [ ] 保留独立证据、行为卡与结构化片段；短文保持全文，长文按主体/行为结构处理，保留父级与原文区间，不硬拆条件和否定。
- [ ] 从有证据的字段生成简短模板背景：来源、主体、角色、明确时间和限制；前缀与原文分开，保留依赖版本。无需让模型为每块重新写长摘要。
- [ ] 导出统一case/behavior/unit ID、来源、权限、用途和审核状态；语义与关键词输入可共用正确背景，但不虚构嵌入、索引或召回效果。
- [ ] 用程序生成明确责任回链、来源/案件/行为/未知/审批等基本计数，以及入口→案件概览→证据/全文的阅读导航。罚款不跨角色、币种或重复行为随意求和。
- [ ] 做最小离线回源检查：链接、字段定位、关键词查找和明确责任关系可用。使用项目外自建查询，不读取比赛测试题和答案；不部署在线服务。

**交付／通过条件：**片段不丢主体和限定，派生物与输入同版本，入口和回链有效，统计可复算。教材：结构切分，第81页；全局统计，第87–88页；关系限定，第89–90页；文件导航，第91页；上下文与双层背景，第96–98页。

### B07 完成人工验收和基础质量报告

**对应：**S16、S18、S31–S32。**状态：**人工批准仍为0，独立内容指标待建立。

- [ ] 使用已预留的360份文书冻结独立验收抽样；不把预留文书数当作已验收案件数。若规模小于原建议300案，明确规模变更，不声称原验收标准已完成。
- [ ] 人工核对主体、处罚金额及归属、应有行为、标签条件、否定/未知和关联关系；涉及跨案结论的实际产物，也单独抽审其支持与限定。
- [ ] 沿用原清单事实≥98%、行为完整≥95%、标签/场景等≥95%、条件/否定≥98%的建议门槛；报告实际分母与争议，未取得人工数据时不报告达标。抽样覆盖或规模不足单列限制。
- [ ] 已知错主体、错处罚归属、实质金额错、伪造原话和虚假批准必须修复或隔离，追查影响范围；不能靠减少标签或堆null掩盖遗漏。

**交付／通过条件：**有真实人审记录、分项结果与未解决事项；通过范围绑定对象、字段、原值、来源及用途，不因一次抽样通过而批量伪造逐条批准。教材：三层评估，第73–74页；来源核验与审查，第92、100–101页。数值门槛来自项目规划。

### B08 冻结交付并验证恢复

**对应：**S05、S30、S35、S40基础部分。**状态：**基础包与30份候选冻结完成，全量版本和独立恢复演练待做。

- [ ] 分开candidate、真实批准范围、待审与隔离；交付八表、必要原文/原件依赖、片段、导航、报告和运行配置。
- [ ] 写入manifest，核对文件全集、字节和SHA；在独立恢复目录验证来源、ID、引用、入口，并重建确定性投影和基本统计。
- [ ] 交付覆盖报告、模型复核与人审结果、实际费用/未知项、失败队列和使用限制。保留上个完整版本，默认旧库切换按实际批准范围另行处理。

**交付／通过条件：**候选构建完成、完整性通过和实际人工批准分别报告；归档脚本依赖及外部原件依赖明确。教材：文件与版本管理，第91页；三层分离及可回滚，第92、100–101页。

|D6|完成目标差集与重点问题处置，汇总B07验收|独立抽样判定、关键问题处置、残余缺口与实际重建成功范围|
|D7|B08整包检查、独立恢复与交付|manifest完整性、恢复结果、候选/真实批准范围、未解决清单|

这是目标排期，不是已验证的产能承诺。按9,999份TXT粗算，七天平均约1,430份/天；若主要生产只有五天则约2,000份/天，包含经核实的重复/非目标材料分流。D1实测未达到所需速度时，当天调整并发、输出负担和增强范围；不能在最后用失败隔离充当成功，或把真实人审全部留到最后一天。
